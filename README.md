# AeroGuard

Pre-flight risk and compliance intelligence for commercial drone fleets—especially infrastructure inspection operators scaling toward repeatable, BVLOS-ready operations.

## What this repo contains

Planning and build specs for AeroGuard (software-first MVP; no flight control or hardware):

## Product direction

**Positioning:** Mission-risk scoring and compliance intelligence—not a generic fleet-management platform.

**MVP promise:** Upload drone logs, define a mission, assign drone/battery/pilot, check weather and airspace, score mission risk with explanations, and export an audit-ready compliance binder.

**First customers:** Small-to-mid drone service providers (5–50 aircraft) doing utility, solar, telecom, pipeline, rail, construction, and industrial inspection.

## Status

Documentation and product specification only—application code not yet in this repository.
